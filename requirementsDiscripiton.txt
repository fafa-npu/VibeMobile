## 项目需求（面向 AI coding agent 的可执行规格）

### 背景
- 我经常用 Claude Code 在电脑上执行编程任务。
- 某些任务会运行很久；我在等待期间可能离开电脑（只带手机外出）。
- 我希望在离开电脑时也能知道 Claude Code/当前任务的运行状态，并在必要时向正在运行的任务发送新的指令。

### 目标（MVP）
1. 在手机端实时/准实时查看：电脑上正在运行的“项目/指令”的状态与输出进展。
2. 在手机端发送新的指令：把指令转发到电脑端当前运行的会话/任务中继续执行。

### 术语定义（避免歧义）
- **电脑端**：运行 Claude Code 的机器（本地 Mac/PC）。
- **手机端**：用于查看状态并发送指令的移动端（iOS/Android 先不限定）。
- **任务（Task）**：一次 Claude Code 的运行单元（可能对应一次命令、一次会话或一个 job）。
- **状态（Status）**：任务当前阶段与健康信息的集合。
- **输出（Logs/Output）**：任务产生的标准输出/关键事件信息。

### 核心功能需求
#### F1. 任务状态查询（手机端）
- 手机端能看到“当前正在运行的任务列表”，并支持**同时多个任务并行**。
- 对每个任务，至少提供以下字段：
	- 任务标识 `taskId`
	- 状态枚举：`running | succeeded | failed | canceled`
	- 最近更新时间 `updatedAt`
	- 最新输出片段（最近 N 行或最近一段文本）

#### F2. 状态更新机制
- 当电脑端任务状态/输出更新时，手机端能在合理延迟内看到更新。
- 更新机制采用**推送（WebSocket）**为主。
- 允许增加轮询作为降级手段（例如 WebSocket 不可用时），但推送必须是默认路径。

#### F3. 发送新指令（手机端 -> 电脑端）
- 手机端可以选择一个 `taskId` 并发送文本指令 `command`。
- 电脑端收到后，将指令注入到对应任务/会话中执行（具体注入方式由实现决定，但必须可追踪）。
- 手机端能看到该指令的送达与处理结果（至少：已接收/执行中/执行完成/执行失败）。

### 非目标（MVP 不做）
- 不要求在手机端编辑代码、查看完整仓库文件树、或进行复杂的 IDE 交互。
- 不做多用户协作、权限分级、团队管理等复杂管理功能（除非后续明确需要）。

### 约束与假设
- 电脑端可能在家/公司网络环境；手机端在外网/蜂窝网络。
- **必须支持外网访问**（手机端不在同一局域网也能访问电脑端任务状态并下发指令）。
- 连接必须安全（至少需要身份验证与传输加密）；具体方案待定。
- 任务输出可能较长：需要分页/截断策略（如“只保留最近 N 行/最近 M KB”）。

### 典型流程（最小闭环）
1. 电脑端启动并开始运行一个任务（产生 `taskId`）。
2. 手机端打开后可看到该任务为 `running`，并持续看到输出更新。
3. 手机端发送一条新指令到该 `taskId`。
4. 电脑端执行该指令并产生新的输出；手机端看到指令执行结果与新增输出。
5. 任务结束后，手机端看到 `succeeded/failed/canceled`。

### 验收标准（可测试）
- A1：电脑端启动一个长任务后，手机端在不超过 **60s** 内能看到任务为 `running`。
- A2：任务每产生新的输出，手机端在不超过 **60s** 内能看到新增内容。
- A3：手机端发送指令后，电脑端在不超过 **60s** 内确认已接收；且该指令的输出可在手机端可见。
- A4：断网/切后台后恢复，手机端能重新连接并继续看到最新状态（允许出现短暂重连）。

### 已确认决策（实现必须遵循）
1. **Claude Code 形态**：CLI 工具。
2. **并发模型**：同时多个任务并行。
3. **状态更新**：推送（WebSocket）。
4. **客户端形态**：可先做 Web（可做成 PWA）；需考虑跨平台，后续可选用 Flutter 做统一客户端。
5. **网络可达性**：需要外网访问。

### 关键技术要求（必须落地）
#### T1. Claude Code CLI 的“会话/任务注入”能力
- 必须调研并实现：在任务运行过程中，如何将手机端发送的 `command` 注入到对应的 Claude Code CLI 会话/任务中执行。
- 该注入机制需要满足：
	- 可将命令路由到指定 `taskId`（多任务并行时不能串线）。
	- 注入行为可追踪（手机端可看到已接收/执行中/完成/失败）。
	- 不依赖手动操作电脑端 UI。

### 已确定参数
1. 延迟目标：A1/A2/A3 均为 **60s**。
