1. 系统概述

VibeMobile 是一个用于远程监控和控制 Claude Code 会话的系统。它允许你通过手机或其他设备远程查看 Claude Code 的输出、发送命令，并在任务完成时收到推送通知。

✨ 主要功能
  • 实时监控 - 通过 WebSocket 实时查看 Claude Code 会话输出
  • 远程控制 - 从任何设备发送命令到 Claude Code
  • 安全访问 - 通过 Cloudflare Tunnel 安全访问，支持 Cloudflare Access 认证
  • 任务通知 - Claude 任务完成时收到浏览器推送通知
  • 多会话管理 - 同时管理多个 Claude Code 会话

4. 安装步骤

4.1 安装必要工具

macOS (使用 Homebrew)

# 安装 Homebrew (如果没有)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装必要工具
brew install node python tmux cloudflared mkcert

# 安装 mkcert 根证书
mkcert -install

# 验证安装
node --version      # 应显示 v18.x.x 或更高
python3 --version   # 应显示 Python 3.10.x 或更高
tmux -V             # 应显示 tmux 3.x
cloudflared --version

Ubuntu/Debian

# 更新包管理器
sudo apt update

# 安装 Node.js (通过 NodeSource)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 安装 Python
sudo apt install -y python3 python3-pip python3-venv

# 安装 tmux
sudo apt install -y tmux

# 安装 cloudflared
curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o cloudflared.deb
sudo dpkg -i cloudflared.deb

# 安装 mkcert
sudo apt install -y libnss3-tools
curl -L https://github.com/FiloSottile/mkcert/releases/latest/download/mkcert-v*-linux-amd64 -o mkcert
chmod +x mkcert
sudo mv mkcert /usr/local/bin/
mkcert -install

4.2 生成 SSL 证书

ℹ️ 为什么需要 SSL？
浏览器的推送通知 API 和 Service Worker 需要安全上下文 (HTTPS)。本地开发使用自签名证书。 
# 进入项目目录
cd /path/to/VibeMobile

# 创建证书目录
mkdir -p certs

# 生成本地证书
mkcert -key-file certs/localhost-key.pem -cert-file certs/localhost.pem localhost 127.0.0.1 ::1

# 验证证书
ls -la certs/
# 应该看到:
# - localhost-key.pem (私钥)
# - localhost.pem (证书)

5. Cloudflare Tunnel 配置

⚠️ 前提条件
需要拥有 Cloudflare 账号和已托管在 Cloudflare 的域名。如果只在本地使用，可以跳过此部分。

5.1 创建 Tunnel

1

登录 Cloudflare

cloudflared tunnel login

这将打开浏览器，授权后会在 ~/.cloudflared/ 创建 cert.pem 文件。

2

创建隧道

# 创建名为 VibeMobile 的隧道
cloudflared tunnel create VibeMobile

# 输出示例:
# Tunnel credentials written to /Users/xxx/.cloudflared/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.json
# Created tunnel VibeMobile with id xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

记下生成的 Tunnel ID 和 credentials 文件路径。

3

验证隧道

cloudflared tunnel list

# 应显示:
# ID                                   NAME       CREATED
# xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx VibeMobile 2025-xx-xxTxx:xx:xxZ

5.2 配置 DNS

# 将域名路由到隧道
cloudflared tunnel route dns VibeMobile your-subdomain.your-domain.com

# 示例:
cloudflared tunnel route dns VibeMobile vibe.example.com

# 输出:
# Added CNAME vibe.example.com which will route to this tunnel
ℹ️ DNS 记录
此命令会自动在 Cloudflare DNS 中创建 CNAME 记录，指向隧道。

5.3 配置文件

创建 ~/.cloudflared/config.yml 文件:

# ~/.cloudflared/config.yml

tunnel: VibeMobile
credentials-file: /Users/YOUR_USERNAME/.cloudflared/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.json

ingress:
  # API 端点 - 路由到后端服务器
  # 使用正则表达式确保只匹配 /api/ 开头的路径
  - hostname: your-subdomain.your-domain.com
    path: ^/api/.*$
    service: https://localhost:8765
    originRequest:
      noTLSVerify: true

  # WebSocket 端点
  - hostname: your-subdomain.your-domain.com
    path: ^/ws$
    service: https://localhost:8765
    originRequest:
      noTLSVerify: true

  # 健康检查端点
  - hostname: your-subdomain.your-domain.com
    path: ^/health$
    service: https://localhost:8765
    originRequest:
      noTLSVerify: true

  # Web UI - 默认路由
  - hostname: your-subdomain.your-domain.com
    service: https://localhost:5173
    originRequest:
      noTLSVerify: true

  # 兜底规则
  - service: http_status:404
🚨 重要提示
  • 必须使用正则表达式 ^/api/.*$ 而不是 /api/*，否则可能错误匹配包含 "api" 的其他路径
  • credentials-file 路径必须是绝对路径
  • noTLSVerify: true 是必需的，因为使用自签名证书

验证配置

cloudflared tunnel ingress validate

# 应显示:
# Validating rules from /Users/xxx/.cloudflared/config.yml
# OK

6. 启动服务

方式一: 使用 Desktop App (推荐)

Desktop App 提供图形界面，可以一键启动/停止所有服务。

# 启动 Desktop App
cd /path/to/VibeMobile/desktop
flutter run -d macos

在 Desktop App 中:

  1. 点击 Start API 启动 API Server
  2. 点击 Start Web 启动 Web UI
  3. 点击 Start Tunnel 启动 Cloudflare Tunnel
  4. 或者点击 Start All 一键启动所有服务

方式二: 命令行手动启动

1. 启动 API Server

# 终端 1
cd /path/to/VibeMobile/server
source venv/bin/activate  # 如果使用虚拟环境
python -m server.main

# 或使用 uvicorn
uvicorn server.main:app --host 0.0.0.0 --port 8765 --ssl-keyfile ../certs/localhost-key.pem --ssl-certfile ../certs/localhost.pem

2. 启动 Web UI

# 终端 2
cd /path/to/VibeMobile/web
npm run dev

# 输出:
#   VITE v5.x.x  ready in xxx ms
#   ➜  Local:   https://localhost:5173/

3. 启动 Cloudflare Tunnel

# 终端 3
cloudflared tunnel run VibeMobile

# 看到以下输出表示连接成功:
# INF Registered tunnel connection connIndex=0 ...
# INF Registered tunnel connection connIndex=1 ...

服务状态检查

# 检查 API Server
curl -k https://localhost:8765/health

7. 使用方法

7.1 首次设备配对

  1. 在手机或其他设备的浏览器中访问 https://your-subdomain.your-domain.com
  2. 如果配置了 Cloudflare Access，需要先完成身份验证
  3. 看到"设备配对"页面
  4. 在 Desktop App 中点击 Devices → 配对新设备
  5. 将显示的 6 位配对码输入到手机浏览器中
  6. 点击"连接设备"完成配对

7.2 查看 Claude Code 会话

  1. 配对成功后，会看到当前所有 Claude Code 会话列表
  2. 点击会话卡片查看详细输出
  3. 输出会实时更新 (通过 WebSocket)

7.3 发送命令

  1. 在会话详情页底部有命令输入框
  2. 输入要发送给 Claude 的消息
  3. 点击发送或按 Enter

7.4 创建新会话

  1. 在会话列表页点击 + 按钮
  2. 输入工作目录路径
  3. 输入启动命令 (默认为 claude)
  4. 点击创建

8. 任务完成通知配置

VibeMobile 支持在 Claude Code 任务完成时发送浏览器推送通知。这通过 Claude Code 的 Hooks 机制实现。

8.1 配置 Claude Code Hook

在项目目录或全局 Claude 配置中添加 Stop hook:

方法一: 项目级配置

创建或编辑 .claude/settings.json:

{
  "hooks": {
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": ".claude/hooks/notify.sh"
          }
        ]
      }
    ]
  }
}

方法二: 全局配置

编辑 ~/.claude/settings.json:

{
  "hooks": {
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "curl -k -s -X POST https://localhost:8765/api/notifications -H 'Content-Type: application/json' -d '{\"type\":\"task_complete\",\"message\":\"Claude 任务已完成\",\"priority\":\"high\",\"sound\":true}'"
          }
        ]
      }
    ]
  }
}

8.2 通知脚本 (可选)

创建 .claude/hooks/notify.sh 获得更灵活的配置:

#!/bin/bash
#
# VibeMobile Task Completion Notification Hook
#

# 配置
VIBE_SERVER_URL="${VIBE_SERVER_URL:-https://localhost:8765}"
VIBE_NOTIFICATION_ENABLED="${VIBE_NOTIFICATION_ENABLED:-true}"

# 如果禁用则退出
if [ "$VIBE_NOTIFICATION_ENABLED" = "false" ]; then
    exit 0
fi

# 发送通知
curl -k -s -o /dev/null \
    -X POST "${VIBE_SERVER_URL}/api/notifications" \
    -H "Content-Type: application/json" \
    -d '{
        "type": "task_complete",
        "message": "Claude 任务已完成",
        "priority": "high",
        "sound": true
    }' \
    --connect-timeout 5 \
    --max-time 10

exit 0

设置执行权限:

chmod +x .claude/hooks/notify.sh

8.3 通知类型

类型 说明 触发场景
task_complete 任务完成 Claude Stop hook
task_error 任务出错 自定义错误处理
permission_required 需要权限 Claude 等待用户确认
session_idle 会话空闲 长时间无活动
custom 自定义 任意场景

8.4 浏览器通知权限

ℹ️ 权限请求
首次使用时，浏览器会请求通知权限。请点击"允许"以接收推送通知。

9. 故障排除

❌ Tunnel 连接失败: "VibeMobile is neither the ID nor the name of any of your tunnels"

原因: 隧道未创建或名称错误

解决:

# 检查隧道列表
cloudflared tunnel list

# 如果没有，创建隧道
cloudflared tunnel create VibeMobile
❌ 页面显示空白

原因: cloudflared path 规则匹配错误

解决: 确保 config.yml 中使用正则表达式:

# 正确 ✅
path: ^/api/.*$

# 错误 ❌
path: /api/*
❌ WebSocket 连接失败

原因: WebSocket 端点未正确配置或被 Cloudflare Access 拦截

解决:

  1. 确保 /ws 路由在 config.yml 中正确配置
  2. 如果使用 Cloudflare Access，考虑为 WebSocket 路径添加 Bypass 策略
❌ SSL 证书错误

原因: 证书未生成或路径错误

解决:

# 重新生成证书
cd /path/to/VibeMobile
mkcert -key-file certs/localhost-key.pem -cert-file certs/localhost.pem localhost 127.0.0.1 ::1

# 验证证书存在
ls -la certs/
❌ "Unable to reach the origin service"

原因: 本地服务未启动

解决:

# 检查服务是否运行
lsof -i :8765  # API Server
lsof -i :5173  # Web UI

# 如果没有输出，启动相应服务
❌ 通知不显示

原因: 浏览器通知权限未授予

解决:

  1. 检查浏览器地址栏左侧的锁图标
  2. 点击并确保"通知"权限为"允许"
  3. 刷新页面
