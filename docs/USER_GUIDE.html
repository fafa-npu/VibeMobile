📋 概述

VibeMobile 让你可以在手机或平板上远程监控和控制 Claude Code 终端会话。无论你是在会议中、通勤途中还是躺在沙发上，都可以随时查看 AI 编程助手的工作进度。

核心功能

🔴 实时输出

通过 WebSocket 实时推送终端输出，延迟低于 200ms

⌨️ 远程输入

发送消息和命令到 Claude Code 会话

🎛️ 特殊按键

支持 Ctrl+C、Escape、Enter 等特殊键

📷 图片上传

直接从手机上传截图或图片到会话

🔐 安全配对

6位配对码 + 桌面确认的双重验证

🌐 远程访问

通过 Cloudflare Tunnel 安全访问

系统组成

组件 说明 端口
Node.js 服务器 提供 REST API 和 WebSocket 服务 8765
Web UI 移动友好的 React 应用 (同上)

🔧 安装指南

系统要求

  • macOS 12.0 或更高版本
✨
一键安装：VibeMobile 支持自动配置，首次启动会自动检测并安装所需依赖。

方式一：一键脚本安装（推荐）

打开终端，运行以下命令：

curl -fsSL https://vibemobile.dev/install | bash

脚本会自动完成以下操作：

  • ✓ 检测并安装 Homebrew（如需要）
  • ✓ 安装 tmux、mkcert、Node.js
  • ✓ 生成 SSL 证书
  • ✓ 下载并安装 VibeMobile.app
  • ✓ 启动应用

方式二：下载 DMG 安装包

下载安装包

从 GitHub Releases 下载最新版本的 DMG 安装包。

安装应用

打开 DMG 文件，将 VibeMobile.app 拖入 Applications 文件夹。

首次启动

运行 VibeMobile.app，应用会自动检测环境并引导你完成配置：

  • 如果缺少依赖，会自动显示安装向导
  • 点击 Install All 一键安装所有依赖
  • 安装完成后自动进入主界面

方式三：从源码构建（开发者）

点击展开详细步骤

克隆项目并构建

# 克隆项目
git clone https://github.com/your-repo/VibeMobile.git
cd VibeMobile

# 安装依赖并构建 Web 服务
cd web
npm install
npm run build

# 构建桌面应用（可选）
cd ../desktop
flutter pub get
flutter build macos --release
💡
提示：大多数用户只需使用方式一或方式二即可，无需手动配置任何依赖。

🚀 快速开始

方式一：使用桌面应用 (推荐)

打开 VibeMobile.app

双击运行桌面应用，应用会自动检测项目路径。

启动服务

点击 Start Server 按钮启动后端服务。

状态变为 Running 表示启动成功。

创建 Claude Code 会话

点击 + 按钮创建新的 tmux 会话，自动启动 Claude Code。

在手机上访问

打开手机浏览器，访问 https://你的电脑IP:8765

首次访问需要配对（见下方说明）。

方式二：命令行启动

# 启动服务器
cd VibeMobile/web
npm start

# 创建 Claude Code 会话 (新终端窗口)
tmux new-session -d -s vibe-1 'claude'

# 查看已有会话
tmux list-sessions

设备配对流程

手机打开 Web UI

在浏览器中打开服务地址，会显示配对界面。

桌面端生成配对码

在桌面应用中，点击 Devices → Generate Pairing Code。

会显示一个 6 位数字配对码，有效期 5 分钟。

输入配对码

在手机上输入配对码并提交。

桌面端确认

桌面应用会弹出确认对话框，显示设备信息。点击 Approve 完成配对。

✅
配对成功：手机会自动跳转到会话列表，现在可以开始使用了！

🖥️ 桌面应用指南

主界面

桌面应用是 VibeMobile 的控制中心，提供以下功能：

状态卡片

卡片 说明 操作
Server Node.js 后端服务状态 Start / Stop / Restart
Web UI Web 界面状态 (与 Server 统一) Open in Browser
Tunnel Cloudflare 隧道状态 Start / Stop / Copy URL

会话列表

显示所有 vibe- 前缀的 tmux 会话：

  • Active - Claude 进程正在运行
  • Ended - 会话存在但 Claude 已退出

设备管理

点击顶部 Devices 图标进入设备管理页面：

  • 查看所有已配对设备
  • 生成新的配对码
  • 修改设备信任等级
  • 删除不再使用的设备

信任等级

等级 权限 适用场景
Full 所有操作 自己的手机
Partial 发送消息、上传文件 临时使用的设备
View Only 仅查看输出 演示给他人看

设置

点击顶部 Settings 图标进入设置页面：

  • API Port: 服务器端口 (默认 8765)
  • Session Prefix: tmux 会话前缀 (默认 vibe)
  • Tunnel Proxy: 代理设置 (用于网络受限环境)

日志查看

点击顶部 Logs 图标查看详细日志，有助于排查问题。

📱 Web 界面指南

会话列表页

这是登录后的首页，显示所有 Claude Code 会话：

  • 每个卡片显示会话 ID、项目路径、状态和最近输出预览
  • 点击卡片进入会话详情
  • 下拉刷新更新列表

会话详情页

这是与 Claude Code 交互的主要界面：

顶部导航栏

  • 返回按钮 - 回到会话列表
  • 会话名称和状态
  • 项目路径 (可点击复制)

终端输出区

  • 实时显示 Claude Code 的输出
  • 支持 ANSI 颜色渲染
  • 自动滚动到底部 (可关闭)
  • 点击任意位置可以暂停自动滚动

输入区域

  • 文本输入框 - 输入消息或命令
  • 发送按钮 - 发送消息 (自动按 Enter)
  • 特殊键工具栏：
    • Ctrl+C - 中断当前操作
    • Escape - 取消/退出
    • Enter - 确认
    • Tab - 自动补全

图片上传

点击工具栏的相机图标上传图片：

  1. 选择图片文件 (支持 PNG, JPG, GIF, WebP)
  2. 图片会上传到服务器并自动发送路径到 Claude
  3. 最大支持 10MB 文件
⚠️
注意：图片上传后不会立即发送，需要手动点击发送或按 Enter。这让你有机会添加说明文字。

🌐 远程访问设置

局域网访问

如果手机和电脑在同一网络：

获取电脑 IP

# macOS
ipconfig getifaddr en0   # Wi-Fi
ipconfig getifaddr en1   # 有线

手机访问

在浏览器中打开 https://192.168.x.x:8765

信任证书

首次访问会提示证书不安全，点击「高级」→「继续访问」。

公网访问 (Cloudflare Tunnel)

如果需要从任意网络访问，可以使用 Cloudflare Tunnel：

安装 cloudflared

brew install cloudflared

启动隧道

  1. 在桌面应用中，点击 Tunnel 卡片的 Start
  2. 等待隧道建立 (约 5-10 秒)
  3. 复制生成的公网 URL (格式: https://xxx.trycloudflare.com)
  4. 在任意设备上访问该 URL
ℹ️
说明：Cloudflare Tunnel 使用的是临时 URL，每次启动都会变化。如需固定域名，可以配置 Cloudflare Zero Trust。

代理设置

如果网络环境需要代理：

  1. 打开桌面应用的 Settings
  2. 在 Tunnel Proxy 中填入代理地址，如 http://127.0.0.1:7890
  3. 保存后重启隧道

🔐 安全说明

认证机制

  • 配对码验证：6位数字，5分钟有效，一次性使用
  • 桌面确认：配对请求需要在桌面端手动批准
  • JWT Token：
    • Access Token: 15分钟有效
    • Refresh Token: 30天有效，存储在 HttpOnly Cookie

权限控制

操作 风险等级 所需权限
查看输出 低 view_only 以上
发送消息 中 partial 以上
上传文件 中 partial 以上
发送 Ctrl+C 高 full
创建/删除会话 高 full

本地访问特权

从 localhost (127.0.0.1) 发起的请求自动获得 full 权限，无需认证。这确保了：

  • 桌面应用可以完全控制服务
  • 本地调试和测试不受限制

审计日志

所有操作都会记录日志，包括：

  • 设备 ID 和名称
  • 操作类型和目标
  • 来源 IP 地址
  • 操作结果 (success/blocked)
  • 时间戳
🚨
安全提醒：
  • 不要在公共场合展示配对码
  • 定期清理不使用的设备
  • 使用 Tunnel 时注意 URL 保密

❓ 常见问题

连接问题

Q: 手机无法访问服务器

A: 请检查：

  1. 手机和电脑是否在同一 Wi-Fi 网络
  2. 电脑防火墙是否允许 8765 端口
  3. 是否使用了正确的 IP 地址

Q: 证书错误/不安全警告

A: 这是因为使用了自签名证书，属于正常现象：

  1. 在浏览器中点击「高级」或「显示详情」
  2. 点击「继续访问」或「访问此网站」
  3. iOS Safari 可能需要在「设置」→「通用」→「关于本机」→「证书信任设置」中手动信任

Q: WebSocket 连接失败

A: 尝试以下步骤：

  1. 刷新页面
  2. 检查服务器是否正在运行
  3. 确认证书已被浏览器信任
  4. 查看浏览器控制台的具体错误信息

会话问题

Q: 会话列表为空

A: 确保：

  1. 已创建 tmux 会话
  2. 会话名称以 vibe- 开头
  3. 运行 tmux list-sessions 检查

Q: 会话显示 "Ended" 但 Claude 还在运行

A: 这可能是进程检测问题。服务器通过 ps 命令检查 Claude 进程，某些情况下可能检测不到。重启服务器通常可以解决。

配对问题

Q: 配对码无效

A: 配对码有 5 分钟有效期，且只能使用一次。请重新生成配对码。

Q: 配对请求没有弹窗

A: 确保桌面应用在前台运行，并检查系统是否允许应用显示通知。

性能问题

Q: 输出更新延迟高

A: 正常延迟应在 200ms 左右。如果延迟过高：

  • 检查网络连接质量
  • 使用局域网而非 Tunnel
  • 关闭其他占用带宽的应用

Q: 页面卡顿

A: 如果输出内容过多，可能导致渲染卡顿。尝试切换到其他会话再切回来，会重新加载最近的输出。
